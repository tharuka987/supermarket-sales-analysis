# Supermarket Sales Analysis

Data Analysis project using Python, Pandas and Matplotlib.

## What I Did
- Cleaned supermarket sales data
- Analyzed sales by product line, city and customer type
- Found which products make the most profit
- Created charts to show sales trends

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Key Findings
- Most sales came from Food and Beverages
- Yangon branch had the highest sales
- Members spent more than normal customers
